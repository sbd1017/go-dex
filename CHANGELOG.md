# Changelog

## 1.0.0

First release.

* Pokédex grid with silhouettes, type-tinted cards and collection icons; one simple "in your Pokédex" rule; floating
  region picker; species and forms grouping.
* Variant-level records: forms, costumes, regional forms, Megas, Gigantamax, Dynamax, shiny, Shadow and
  Purified, with per-Pokémon details (size, lucky, IVs, background, gender, moves, CP, notes).
* One search language for the Pokédex, wishlist and trade pages, kept in the address bar for sharing.
* Wishlist with requirements, priorities, tags and "you already have one" matching.
* Trade page with quantities, "copy as text" and a compare tool for visitors.
* Stats with links back to the matching searches.
* Admin: quick toggles, quick entry on the grid, special entries, bulk actions, paste a list, JSON/CSV export,
  repeatable JSON import with a dry run, undo for every change.
* Link previews, Add to Home Screen, versioned static files.
* Copy for Pokémon GO: any result as an in-game search string (Pokédex numbers plus GO words).
* Catalog: shinies per form and costume from Leek Duck's shiny list; older costumes (stored as "costumes" rather
  than forms in the game data) included; weekly checked updates on the server with a "what's new" list.
